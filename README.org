Hi! Here is my .dotfiles, mainly composed of Emacs config files and Vim.

* About me
I am a PhD student in Physics, focusing on glaciology. I do numerical modelling. I am enthusiastic about machine learning methods and trying to use them in my project.
* Emacs
- Doom Emacs + Evil mode
- IDE:
  - Main languages: Python, C++, bash, Elips
  - LSP and DAP
  - Version control (magit)
- Terminal emulation (multi-vterm).
- Org mode: note taking, knowledge network (roam), todos, agenda, latex rendering, presentations, programming... 
- Email client (mu4e).
- IRC
- Scientific research:
  - Writing: Org and Latex
  - citar for bib management + roam integration
- LLM assistant client (gptel, my favorite LLM is Mistral/Codestral)
- HPC task automation:
  - submit batch script with keybinding
  - quick monitoring of slurm queue state
  - open .nc file with ncview by default
  - display .nc metadata from either ncdump or cdo as file preview
- Window manager (exwm): managing my none-emacs buffers (qutebrowser, Spotify, ncview, matplotlib, Ardour...).

* Notes on the phone
I manage all my notes with org-roam. On my phone I use the [[https://github.com/Artawower/orgnote-client][OrgNote]] app, which opens my org files directly from a folder on the phone. [[https://syncthing.net][Syncthing]] keeps the laptop and the phone in sync, with my Raspberry Pi as the always-on, self-hosted hub, reachable from outside through WireGuard. The setup script and ignore patterns are in =syncthing/=.
