* System monitor in a buffer
Since Emacs is my window manager, I wanted a system monitor one keystroke away rather than an app to open. =s-o m= shows [[https://github.com/aristocratos/btop][btop]] in a regular buffer, so it can sit in any window next to my terminal and my scripts.

It is a small module, [[file:emacs/modules/anthe-sysmon.el][anthe-sysmon.el]], that runs btop in [[https://github.com/akermu/emacs-libvterm][vterm]]:
- Read-only: no key reaches btop, so no process gets killed by accident. The leader key still works, to move around windows. =q= kills the buffer and btop with it.
- Follows the Emacs theme: btop's =TTY= theme uses the 16 terminal colors, which vterm takes from the Emacs faces.
- Paused when hidden: btop is stopped while no window displays the buffer, and resumed when one does.
- Plays well with popups: its own major mode, derived from =vterm-mode=, keeps it out of popper.

It is written for Doom Emacs (it uses =doom-cache-dir= and =doom/leader=) and the keybinding is set in my EXWM config. btop needs a window of at least 80x24 to show all its boxes.

* Notes on the phone
I manage all my notes with org-roam. On my phone I use the [[https://github.com/Artawower/orgnote-client][OrgNote]] app, which opens my org files directly from a folder on the phone. [[https://syncthing.net][Syncthing]] keeps the laptop and the phone in sync, with my Raspberry Pi as the always-on, self-hosted hub, reachable from outside through WireGuard. The setup script and ignore patterns are in =syncthing/=.
